## Visual language

- Near-black/deep navy technical sections
- Warm stone/ivory editorial sections
- Restrained teal for active security signals
- Warm gold for governance/priority indicators
- Monospace labels and modern sans-serif headlines
- No hacker imagery, padlocks, Matrix code or decorative cloud icons
- Architecture, evidence and security artefacts provide the visual interest
